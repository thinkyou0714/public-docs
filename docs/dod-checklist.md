# Definition of Done (DoD) チェックリスト

記事を公開する前に、以下の10項目を **すべて** 満たすことを確認する。

## 公開OK基準：10項目

| # | チェック項目 | 確認方法 |
|---|------------|---------|
| 1 | **価値が1行で言える（定性）** | frontmatter の `description` が1行で定性的な価値を述べている。数値なし |
| 2 | **前提条件が明記** | 「前提条件」セクションが存在し、必要な環境・ツール・権限が列挙されている。固有名詞/URL/数値なし |
| 3 | **最短セットアップが画面/項目レベルで再現可能** | 「セットアップ」セクションが手順化されており、操作対象の画面名・設定項目名・操作内容が明記。具体値なし |
| 4 | **詰まりTOP5あり** | 「詰まりTOP5」セクションに5項目が列挙されている |
| 5 | **反証3あり** | 「反証3」セクションに失敗条件が3項目記載されている |
| 6 | **ログ/確認ポイントあり（場所と観点）** | 「運用」「セットアップ」セクション内でログ確認の場所・観点が具体的に述べられている |
| 7 | **停止/復旧/ロールバックあり** | 「ロールバック」セクションに即時停止〜完全戻しの段階が記載されている |
| 8 | **機密ゼロ** | URL/名前/数値/内部リンク/トークン等を含まない。`scripts/check-secrets.sh` でチェック通過 |
| 9 | **FAQ10あり** | 「FAQ10」セクションに10項目のQ&Aが記載されている |
| 10 | **変更履歴＋内部リンク（ID参照）あり** | 「変更履歴」テーブルに日付・変更内容・関連IDが記載。`last_verified` が記載 |

## チェック手順

### 手動チェック

1. 上記10項目を記事ごとに目視確認
2. チェックシートに日付と確認者を記録
3. 1項目でもNGがあれば公開しない

### 自動チェック（補助）

```bash
# 機密チェックスクリプトを実行
npm run check-secrets
# または
node scripts/check-secrets.mjs
```

### レビューフロー

1. 執筆者がDoD自己チェック
2. `scripts/check-secrets.sh` を実行してパス確認
3. レビュワーがDoD 10項目を再確認
4. すべてOKなら `20_publish` へ移動（Obsidian側）、`content/` にコミット（Git側）

## 不合格時の対応

- 不足セクションを追加して再チェック
- 機密混入がある場合は `#secret_suspected` タグを付与し、即座にsanitize
- 修正完了後、変更履歴に修正内容を追記
